# Stylework Lead Tracker — Frontend

Client web application for the Stylework Lead Tracker, built with React, TypeScript, and Vite.

## Tech Stack
- React 19
- TypeScript
- Vite
- Modern Vanilla CSS design system

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   ```
   Set `VITE_API_BASE_URL` to point to the backend server (default: `http://localhost:3000`).

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
